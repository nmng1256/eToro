## eToro 介绍

说起 eToro，你可能已经在 YouTube 上被它的广告轰炸过无数次了。这家公司成立于2007年，总部在以色列，创始人是三个以色列人——Yoni Assia、Ronen Assia 和 David Ring。

eToro 最开始叫 RetailFX，后来才改成现在这个名字。它不是那种传统意义上的券商，更像是一个"社交交易平台"。什么意思呢？就是你不仅可以在上面买卖股票、加密货币、外汇这些东西,还能看到其他投资者在干什么,甚至可以直接"复制"他们的操作——这就是他们最有名的 CopyTrader 功能。

截至2025年,eToro 已经有超过4000万注册用户,分布在140多个国家。2025年5月,eToro 在纳斯达克上市,估值达到56.4亿美元。公司受到多个国家金融监管机构的监管,包括英国FCA、塞浦路斯CySEC、美国SEC和澳洲ASIC等。

平台上可以交易的东西挺丰富的——美股、港股、欧洲股票、ETF、加密货币、外汇、商品期货、指数等等,超过6000种资产。而且它的界面设计得相对简单直观,对新手来说比较友好。

不过要注意的是,在亚洲地区(包括台湾)开户的用户,默认是澳洲监管,交易的主要是差价合约(CFD)而不是真实股票。如果你想持有真实股票,需要联系客服转到欧洲监管,并且以1倍杠杆买入美股时才算是买到实体股票。

台湾金管会曾表示 eToro 并未在台湾取得业务许可,所以严格来说它在台湾不算"合法"——但这跟 TD Ameritrade、Firstrade 这些美股券商的情况差不多。国际上,eToro 的监管和规模都算可靠的。

## eToro 测评

### 用户普遍评价

eToro 在市场上的口碑相当两极化。让我们看看真实用户怎么说。

**优点方面:**

1. **界面友善,新手友好** - 这是最多人认同的优点。相比其他券商复杂的界面,eToro 确实做得比较直观,不会让新手一头雾水。

2. **社交交易功能独特** - CopyTrader 功能让你可以"跟单"厉害的投资者,对于没时间研究或刚入门的人来说挺实用的。Trustpilot 上的评分为4.2/5,99%的负面评论都得到了回应。

3. **资产种类丰富** - 一个平台就能交易股票、加密货币、外汇、商品等,不用开好几个账户。

4. **监管相对完善** - 受到FCA、CySEC、SEC、ASIC等多个主流监管机构监管,2025年还在纳斯达克上市了,透明度提高了不少。

5. **虚拟账户好用** - 10万美元的模拟资金可以让你随便练习,不用担心亏钱。

**缺点方面:**

1. **容易误触高杠杆** - 这是最危险的坑。eToro 默认下单是10倍杠杆,很多新手没注意就下了CFD差价合约单,结果被强制平仓,赔得很惨。Reddit 上有不少用户就是因为这个踩雷。

2. **点差费用偏高** - 虽然号称"零佣金",但通过点差收费。对于频繁交易的人来说,长期累积下来成本不低。加密货币2%的来回费用在业内算偏高的。

3. **系统当机问题** - 2020年后系统稳定性下降,在市场剧烈波动时偶尔会当机,这对于需要及时交易的用户来说很致命。有网友在 PTT 和 Dcard 上都反映过这个问题。

4. **客服质量下滑** - 早期客服响应还不错,但随着用户增长,客服品质有所下降。有用户反映工单系统会进入循环,难以解决问题。

5. **出金手续费** - 虽然5美元不算太高,但频繁出金的话也是一笔开销。不过升到Platinum等级后可以免出金费。

6. **台湾地区法律地位模糊** - 台湾金管会明确表示 eToro 未取得台湾业务许可,虽然不是诈骗平台,但法律保障相对有限。

### 适合哪些人?

根据多方评测,eToro 比较适合:
- 投资新手,想要简单易用的平台
- 长期持有美股和ETF的投资者(点差影响较小)
- 对社交交易功能感兴趣的人
- 想要多元化资产配置的投资者

**不太适合:**
- 频繁短线交易的人(点差成本高)
- 需要交易冷门小型股的人(可能没有对应的CFD)
- 对客服响应速度要求高的人
- 希望参加股东会的长期价值投资者

### 安全性评估

从安全角度来说,eToro 在18年的运营历史中从未发生过导致用户资金损失的黑客攻击事件。2024年虽然面临过SEC的诉讼(涉及未注册经纪商和加密货币证券化问题),但已经以150万美元和解,并逐步重新上架了加密货币资产。

整体来说,eToro 不是诈骗平台,规模和监管都算可靠。但它确实存在服务质量波动、费用结构不够透明等问题。如果你决定使用,建议:
- 一定要注意槓杆设置,不要误触10倍杠杆
- 长期投资者可以考虑,短线交易者慎重
- 先用模拟账户熟悉操作
- 不要一次性投入太多资金
